NICOLE ISRAEL - PORTFOLIO WEBSITE
=================================
Built with HTML, CSS and basic JavaScript only. No npm, React or libraries.

HOW TO OPEN
1. Extract the ZIP.
2. Open the nicole_portfolio folder.
3. Double-click index.html in your browser.
4. To edit code, open the folder in Visual Studio Code.

ADD ANOTHER IMAGE TO A PROJECT
Inside that project's <div class="gallery-track"> add:
<img src="images/image_11.jpg" alt="Description" loading="lazy">
Then add your image_11.jpg to images/. The slideshow counts it automatically.

CHANGE AUTOMATIC SLIDE DELAY
In script.js, change: const AUTO_SLIDE_DELAY = 4500;
Example: 3000 = 3 seconds, 7000 = 7 seconds.

PUBLISHING
This is a static website. You can upload these files to a static website host.


CERTIFICATES SECTION
- Ethical Hacker: images/image_11.jpg
- DICT Webinar - How to Start Your VA Career: images/image_12.jpg
Replace these dummy images with your certificate scans using the same filenames.
Edit certificate names, issuer, and dates in the CERTIFICATES section of index.html.
Use the exact title printed on your Ethical Hacker certificate.
Update each image alt description after replacing the placeholder.
Click a certificate image or View certificate to open the full image in a new tab.
Only HTML, CSS and basic JavaScript are used; no installation is needed.


ABOUT ME PROFILE PHOTO
image_13.jpg: Your profile photo in About Me.
Replace images/image_13.jpg with your portrait using the same filename.
Recommended size: 800 x 1000 pixels (portrait, 4:5 ratio).
Update the image alt text in index.html after adding your own photo.
To adjust the crop, edit object-position in the PROFILE PHOTO CSS block.


HEADER PROFILE
The header shows a circular profile photo beside Nicole Israel.
It shares images/image_13.jpg with the About Me portrait.
Replace that single file to update both places.
Edit the brand-name text in index.html to change your displayed name.
