NICOLE ISRAEL - PORTFOLIO WEBSITE
=================================
Built with HTML, CSS and basic JavaScript only. No npm, React or libraries.

HOW TO OPEN
1. Extract the ZIP.
2. Open the nicole_portfolio folder.
3. Double-click index.html in your browser.
4. To edit code, open the folder in Visual Studio Code.

PUBLISHING
This is a static website. You can upload these files to a static website host.
